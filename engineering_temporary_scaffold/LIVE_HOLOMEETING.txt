Start Live Holomeeting:
```
python -m identity.holographic_shell.commands start_holomeeting <session_id> <participant_count>
```

Join Active Holomeeting:
```
python -m identity.holographic_shell.commands join <session_id> <participant_id>
```

Broadcast Message:
```
python -m identity.holographic_shell.commands broadcast <session_id> <message>
```

Check Session Status:
```
python -m identity.holographic_shell.commands status <session_id>
```

Archive Session:
```
python -m identity.holographic_shell.commands archive <session_id>
```
