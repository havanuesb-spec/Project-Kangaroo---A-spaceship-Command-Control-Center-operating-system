SCAN CODE DEFINITION

Scan Code is a dynamic, real-time code that represents the current operational state
of all Project: Kangaroo subsystems. It is generated continuously by the security layer
and updates as system state changes.

---

SCAN CODE FORMAT

Base Structure: SCAN-[TIMESTAMP]-[LAYER_STATE]-[RISK_HASH]-[INTEGRITY_SIGNATURE]

Example:
SCAN-20260411T224646Z-IHCSM-A7F2B1-7E3D9C4B5A1F2E6D

Components:

1. TIMESTAMP (UTC ISO 8601)
   20260411T224646Z = April 11, 2026, 22:46:46 UTC
   Enables time-sequence verification
   Prevents out-of-order scan acceptance

2. LAYER_STATE (5 characters, one per layer)
   I = Intent Layer state (✓ = ready, ✗ = failed, ~ = degraded)
   H = Capability Layer state
   C = Identity Layer state
   S = Security Layer state
   M = Orchestration/Mediation state

   Example: IHCSM = all layers operational and healthy

3. RISK_HASH (6 hex characters)
   Hash of current risk assessment:
   - freeze_risk
   - bottleneck_risk
   - monopolization_risk
   - lockdown_risk
   - time_reversal_risk
   - gate_lock_status

   A7F2B1 = specific risk profile

4. INTEGRITY_SIGNATURE (16 hex characters)
   SHA256 hash signature of:
   - All layer state hashes
   - Risk profile
   - Timestamp
   - System configuration hash
   - Trust registry state

   7E3D9C4B5A1F2E6D = cryptographic proof of system integrity

LIVE SCAN CODE GENERATION

Trigger Points (every execution):
1. System bootstrap completes
2. Health check runs
3. Runtime mediation executes
4. Intent event processed
5. Capability issued
6. Trust record written
7. Gate lock state changes
8. Transistor state changes
9. Time-reversal check completes
10. Security scan completes

Generation Process:
1. Collect current state from all layers
2. Evaluate risk indicators
3. Hash individual layer states
4. Combine into risk profile
5. Generate cryptographic signature
6. Output scan code with timestamp

---

SCAN CODE VERIFICATION

Valid Scan Code Properties:
✓ Timestamp is recent (within 5 seconds)
✓ Timestamp does not indicate time-reversal
✓ All layer state characters valid
✓ Risk hash corresponds to system state
✓ Integrity signature verifies against all components
✓ Signature matches trust registry records

Invalid Scan Code Triggers:
✗ Timestamp in future (time-reversal detected)
✗ Outdated timestamp (system state stale)
✗ Invalid layer state characters
✗ Risk hash mismatch (state inconsistency)
✗ Signature verification fails
✗ Signature not found in trust registry

---

SCAN CODE COMMAND INTERFACE

Get Current Scan Code:
```
python -m security.scan_code get_current
```

Verify Scan Code:
```
python -m security.scan_code verify <scan_code_string>
```

Get Latest N Scan Codes:
```
python -m security.scan_code history <count>
```

Check Scan Code Validity:
```
python -m security.scan_code check_validity <scan_code_string>
```

Export Scan Code Log:
```
python -m security.scan_code export <start_time> <end_time>
```

INTEGRATION WITH OTHER SYSTEMS

Trust Registry:
- Every scan code generates a trust record
- Signature verified against trust records
- Creates audit trail of system state

Runtime Mediation:
- Risk hash derived from current risk assessment
- Reflects freeze/bottleneck/monopolization status
- Enables real-time risk monitoring

Reverse Nanoclocked:
- Timestamp validated for time-reversal
- Prevents scan codes with backwards timestamps
- Ensures temporal continuity

Gate Lock:
- Scan code required for sensitive operations
- Passkey verification includes scan code validation
- Ensures only current system states unlock
