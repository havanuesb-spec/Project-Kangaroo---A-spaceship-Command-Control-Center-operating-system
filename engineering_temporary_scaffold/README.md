# Engineering Temporary Scaffold

This folder is a temporary engineering access layer for the current Multiverse workspace.

Artifacts:
- `engineering_access_manifest.json`: machine-readable path manifest.
- `engineering_access_index.md`: human-readable entry point index.
- `connectors_index.md`: connector inventory for active and pending dimensions.
- `crystallic_shape_shifting/`: folder hierarchy for crystalline morphology, phase changes, materials, and prototypes.
- `builder.py`: regenerates the manifest and index.

Purpose:
- make it easier for engineering to revisit the intent, security, trust, and dashboard layers later
- provide an access point to the identity shell and crystal-tree layer
- provide a temporary branch for crystallic shape-shifting experiments without disturbing the existing notes
- provide a stable place to hang future access notes, runbooks, and temporary build aids
